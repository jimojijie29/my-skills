# 注入：serenity 方法论原文

## 核心理念：把龙头当"入口"

- 只问逻辑，不当目标：不碰那个名字（龙头），只用它回答一句话："需求"从哪来，会往哪传导？然后顺着这条线，一层层往上游钻。
- 溯游而上：越往上游（部件 -> 芯片 -> 材料 -> 衬底 -> 设备），价值越被低估，关注越少，约束越硬。
- 一句话内核：顺着需求往下钻，直到撞上那个"绕不开"的卡口。

## 什么是真正的"卡口"？

不是淘金时代"卖铲子的人"（因为铲子谁都能造），而是 **河道收窄的地方** —— 水流再大，也只能从这里过。

一个真正的卡口必须 **同时** 满足以下四个条件：
- 条件 1：不可替代
- 条件 2：供给刚性
- 条件 3：寡头垄断
- 条件 4：没人看见

## 流水线：六步"下钻法"

1. 超级周期门槛：只在确认的、多年的大周期里面去挖。
2. 锚定龙头：从共识最强的外部进入，将其当"入口"而非目标，只问需求从哪里来。
3. 逐层下行：顺着产业链一层层往上游钻（龙头 -> 部件 -> 芯片 -> 材料 -> 衬底 -> 设备）。
4. 四个物理追问：每一层都要问以下四个问题，且答案必须全为"是"：
   - 谁是寡头？
   - 扩产多久？
   - 有无替代？
   - 下游必须用吗？
5. 钻到卡口中的卡口：别停留在第一个，继续往下钻，直到 "替不了 + 扩不出 + 寡头 + 没人看" 这四个条件同时成立。
6. 多维排雷：将产能、订单、认证、估值、治理等逐项过一遍。确保卡口是真的，公司也不能是坑。
